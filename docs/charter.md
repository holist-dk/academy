# The Academy - Founding Charter

## Mission
Protect the student's curiosity.

## Purpose
Build an educational institution - not a chatbot - that helps learners become independent Japanese language learners.

## Core Principles
- Evidence over assumptions
- Understanding over memorization
- Real-world application
- Recommend the world - the Academy points learners to real Japanese-speaking resources and communities rather than trying to contain them inside the app

## Working Principles (apply to every decision, every day)
- Update README.md at the end of every completed work day.
- No file exceeds 300 lines. If one wants to, something foundational needs restructuring - that is the signal, not a reason to keep scrolling.
- Agents have no free will. They execute exactly what is specified - no autonomous judgment about what to do, only how to do the specified task.
- Code is 80% deterministic Python, 20% agents (LLM calls). Agents are the exception, not the default tool.
- When a hurdle is hit: stop, discuss, then continue. Never silently push through an unresolved problem.
- This is a long-term project. No rush to ship. Built to last, not built to demo.

## What the Academy Is Not
- Not a single "God Agent" trying to do everything in one prompt.
- Not a chat log or transcript store.
- Not a system that stores conclusions without evidence.
- Not a system that tries to monopolize the learner's time - it recommends the world instead of competing with it.
